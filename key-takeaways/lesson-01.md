# Lesson 01: Các lệnh Git cơ bản

1. `git init`: Khởi tạo Git repository trong thư mục hiện tại.

2. `git add <file_name>`: Đưa một file cụ thể (hoặc các thay đổi trong file đó) vào Staging Area.

3. `git add .`: Đưa toàn bộ thay đổi (bao gồm file mới tạo, file đã chỉnh sửa, file đã bị xóa) từ thư mục hiện tại vào Staging Area.

4. `git commit -m "<message>"`: Lưu lại toàn bộ các thay đổi đang nằm trong Staging Area vào Local Repository kèm thông điệp mô tả.
